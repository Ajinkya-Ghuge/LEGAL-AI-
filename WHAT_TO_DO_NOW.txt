                        POSSIBLE ISSUES & SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

ISSUE 1: "Bucket doesn't exist" error
SOLUTION: 
    1. Go to: https://miiineezxbvmhlxavbfh.supabase.co
    2. Click "Storage" in left sidebar
    3. Click "New bucket"
    4. Name: legal-documents
    5. Toggle "Public bucket" to ON
    6. Click "Create bucket"
    7. Try uploading again

ISSUE 2: "Permission denied" or "403" error
SOLUTION:
    - Your SUPABASE_KEY might not have permission
    - Go to Supabase Dashboard → Settings → API
    - Copy the "anon/public" key (NOT service_role)
    - Update SUPABASE_KEY in Render environment variables

ISSUE 3: "Environment variables not set"
SOLUTION:
    - Go to Render Dashboard → Nexuslaw1 → Environment
    - Make sure these are set:
        SUPABASE_URL=https://miiineezxbvmhlxavbfh.supabase.co
        SUPABASE_KEY=eyJhbGc... (your anon key)
    - Click "Save Changes"
    - Redeploy

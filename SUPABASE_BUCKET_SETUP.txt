═══════════════════════════════════════════════════════════════════════════════
                    STEP 2: SET UP STORAGE POLICIES (OPTIONAL)
═══════════════════════════════════════════════════════════════════════════════

Since we're using the anon key and simple path-based access (user_id/doc_id.pdf),
you can skip RLS policies for now. The application will use signed URLs for access.

However, if you want to add RLS policies later for extra security:

1. Go to Storage → pdfs bucket → Policies
2. Add these policies:

-- Allow users to upload their own PDFs
CREATE POLICY "Users can upload own PDFs"
ON storage.objects FOR INSERT
TO authenticated
WITH CHECK (
  bucket_id = 'pdfs' AND
  (storage.foldername(name))[1] = auth.uid()::text
);

-- Allow users to read their own PDFs
CREATE POLICY "Users can read own PDFs"
ON storage.objects FOR SELECT
TO authenticated
USING (
  bucket_id = 'pdfs' AND
  (storage.foldername(name))[1] = auth.uid()::text
);

-- Allow users to delete their own PDFs
CREATE POLICY "Users can delete own PDFs"
ON storage.objects FOR DELETE
TO authenticated
USING (
  bucket_id = 'pdfs' AND
  (storage.foldername(name))[1] = auth.uid()::text
);
